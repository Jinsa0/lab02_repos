# АП Завдання № 2.0 — «Системи контролю версій»

Репозиторій для лабораторної роботи № 2.0 з дисципліни «Алгоритмізація та програмування».

* **Автор:** Кіц Роман (гр. РІ-12)
* **Мета:** Навчитися працювати з Git, гілками, комітами та віддаленим репозиторієм GitHub.

### Основні використані команди:
* `git init`, `git add`, `git commit` — створення репозиторію та фіксація змін.
* `git checkout -b <branch>`, `git merge` — робота з гілками та їх злиття.
* `git push`, `git pull`, `git fetch` — синхронізація з GitHub.
* `git reset --hard` — скасування змін та відкати.
